ETL and EDA Pipeline

An end-to-end data pipeline that collects data from an API, cleans and validates it, stores it for reuse, and then examines it through structured exploratory data analysis.

ETL stands for Extract, Transform, Load. EDA stands for Exploratory Data Analysis.

  1. Extract

    Collect raw data from a public API.

  2. Transform and validate

    Clean and reshape the data with pandas, and enforce data rules with Pydantic.

  3. Load

    Store the validated data in a database or a file.

  4. Analyse

    Run structured EDA to find patterns, trends and data quality issues.
