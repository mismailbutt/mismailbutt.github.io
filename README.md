# Muhammad Ismail Butt | Portfolio

Personal portfolio website of Muhammad Ismail Butt, BS Artificial Intelligence student at UET Lahore.

Live site: https://mismailbutt.github.io

## Folder contents

| File | Purpose |
|------|---------|
| `index.html` | The complete website (HTML, CSS and JavaScript in one file) |
| `assets/profile.jpg` | Profile photo used for link previews on LinkedIn and WhatsApp |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |
| `README.md` | This file |

## Deploy on GitHub Pages

1. Create a public repository named `mismailbutt.github.io`.
2. Upload everything in this folder, keeping `assets/` as a folder.
3. Go to Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Open https://mismailbutt.github.io after a few minutes.

## Update the site

Edit `index.html` on GitHub (pencil icon), then commit. The live site updates in a few minutes.

## Built with

HTML, CSS and vanilla JavaScript. No frameworks or build step.
